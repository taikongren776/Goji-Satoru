Derived from `limitless-whitehair-study.vrm`, whose CC0 source and edit history are documented in [limitless-whitehair-study.LICENSE.md](limitless-whitehair-study.LICENSE.md) and [fast-track-hairsample-male.LICENSE.md](fast-track-hairsample-male.LICENSE.md).

Original mesh, skinning, textures, morph deltas and materials remain unchanged. Added six baked animation clips, named sockets, a stable Blink name and the existing project's blindfold accessory, refitted to this head. No extracted game asset was used. New animation and accessory fitting edits are released under CC0; this does not grant rights to unrelated character designs.

The `.blend` import uses glTF fallback materials; `.vrm` (a binary glTF container with VRM extensions) is the authoritative browser asset. This is a playable candidate, not final art approval.
