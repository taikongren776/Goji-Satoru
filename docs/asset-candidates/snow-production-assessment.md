## 人工任务拆解

**Head：** 重设成年比例和脸颊/颧骨/下颌关系；修改眼眶、眼睑、眼球暴露量及眼角；设计鼻梁、鼻尖、鼻底；修整口唇与口轮匝肌体积；保持耳廓和耳根衔接。正面、严格侧面、45°及仰俯视统一审查。改脸后重新检查眼口环线、闭眼、口内和眼罩接触，不将单纯拉长旧脸当作风格完成。

**Hair：** 重新设计前后左右剪影、主束/次束、后脑束群、发际线、根部层次和厚度；白色尖发不等于重复锥体。基于实际发束网格逐角检查交叉、法线、尖端和退化面，原Snow发型不作为最终发型保留。

**Clothing：** 人工制作领座与高领内外层、躯干、袖窿、袖山、腋下活动余量、长袖、肘部、袖口、裤腰/裆/膝/裤脚和鞋靴。先解决纸样般的结构关系与布料体积，再设计随姿势变化的褶皱。短袖原网格只供拓扑和权重参考，不能直接外扩皮肤或拉伸袖口宣称完成制服。

**Hands：** 精修掌弓、鱼际/小鱼际、指根高度、指节和指腹；建立合理甲床；检查左右拇指CMC/MCP/IP旋转、对掌接触及腕部连续性。测试张手、半握拳、握拳、对掌和双手动作。现有MakeHuman手部修复保留作对照，不能将其单顶点修复迁移到Snow同编号顶点。

**Rig：** 设计面向线性蒙皮的锁骨/肩胛运动、上臂和前臂扭转辅助、腕、拇指及独立指骨；重绑新比例和衣物。逐姿制作必要的可导出修正形态，验证普通骨骼TRS与morph动画；不能把CloudRig的控制骨数量直接搬进网页。

**Animation：** 六段分别制作或人工清理：Idle呼吸/重心；CastBlue抬手凝聚和收招；CastRed指尖手势与释放；CastPurple双手配合和不相交；RevealEyes/CoverEyes手与眼罩真实接触。保持4/5/4/8/2.4/2.4秒，技能释放点1.65/1.4/4.6秒，揭/戴眼罩提交点0.92/1.32秒。适配器只能映射，不能替代重新定姿、接触修正或动作导演。

## 工作量（定性评估，不是报价或排期）

LOW＝常规整理；MEDIUM＝有限重做和验证；HIGH＝专门人工制作并迭代；VERY HIGH＝跨多个专业工序、需要阶段验收。以下针对目标完整角色，工序存在重叠，不能相加成虚假的精确工时。

| 工作 | 工作量 | 依据 |
|---|---|---|
| 面部重塑 | HIGH | 成年日漫比例与原脸差异大，造型与表情拓扑相互影响 |
| 发型重做 | HIGH | 需要全新发束设计与多视角轮廓 |
| 制服制作 | VERY HIGH | 高领长袖、裤鞋完整资产，不能沿用短袖试作 |
| 手部修整 | HIGH | 起点连续但近景形体及握拳对掌仍待验证 |
| 肩袖拓扑 | HIGH | 袖窿、腋下、领肩联动需人工结构设计 |
| UV | MEDIUM | 源UV可参考，新脸/衣发需重展；UDIM转网页布局 |
| 材质 | HIGH | 完整动漫材质/纹理制作和无发光条件验证 |
| Rig | HIGH | CloudRig到实时骨架不是直接导出 |
| Weight Paint | HIGH | 新体型和服装需重绑，影响数裁剪后须再修权重 |
| Corrective Shapes | HIGH | 肩、腋下、肘、拇指逐姿修形与导出烘焙 |
| Animation cleanup | HIGH | 六动作、双手接触、眼罩、混合/取消均需人工清理 |
| GLB integration | MEDIUM | 适配器已就绪；前提是美术先完成可靠LBS/morph，否则升至HIGH |
| **Overall Art Effort** | **VERY HIGH** | 是专业角色制作项目，不是小修或格式转换 |

现有证据不能给出可靠价格或日期。请美术师按“肩手试作”“完整造型”“绑定动作”“最终导出”分别报价、说明修订轮次和源文件交付；只有试作通过后才考虑后续制作范围。

## 关键风险和退出门槛

| 风险 | 实际依据 | 应对 / 未通过时怎么办 |

## 先行试作与保留项

建议用户授权后，先让美术师交付“上半身高领长袖肩部 + 双手”的独立候选和实时骨架，完成垂臂、前举/侧举45°/90°/120°、旋转、弯肘、组合施术及拳态/对掌。必须有真实Blender/Three.js图、局部线框、权重及连续播放。一轮完整试作仍有结构缺陷则列明根因并暂停，不能继续扩大到脸发或全角色。

本轮未执行该试作。A2双手间距和A3旧手候选的局部修复、全部原诊断均保持；旧头发12个退化面导致的全局FAIL继续有效。路线评估通过不改变Milestone A状态。
